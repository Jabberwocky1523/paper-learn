## 术语规则

- HBM：高带宽内存；HBF：高带宽闪存。
- buffered cache-aware scheduling：带准入余量的缓存感知调度；admission headroom：准入余量；admission fraction：准入比例。
- latency hiding buffer：延迟隐藏缓冲区，指 H³ 读路径中的硬件缓冲区，区别于调度准入余量。
- demotion：下沉；offload：卸载；reload：回载；residency：驻留状态。
- cache churn：缓存反复迁移／缓存抖动；locked footprint：锁定数据占用量。
- shared-site design：共享位置设计；site：堆栈连接位置。
- TP／EP／DPA：张量并行／专家并行／数据并行注意力。
- modeled energy：建模能耗；completion time：固定工作负载完成时间；TPOT：首 token 后的平均每输出 token 时间。
- write endurance：写入耐久性；P/E cycles：编程／擦除次数；write amplification：写放大。

## 原文限定条件与统计口径

1. **性能证据**：纯 HBM 模拟器对单 H100 上 vLLM 的 16 个测试点，吞吐量平均绝对百分比误差为 9.14%。HBF、混合批次和大批量性能仍属于模型外推，不据此表述为实物验证。
2. **能耗模型**：按运算次数、内存访问和通信流量计能耗，不计静态功耗和完整封装功耗。“内核更快”不直接意味着该模型中的能耗更低。
3. **准入余量**：b＝0.9 对应 10% 准入余量。阈值在准入时检查，并不要求每个 decode 步骤都保持固定的 10% 物理空闲分区。A_i 包含重新纳入活跃锁保护的完整缓存前缀。
4. **寿命推算**：按 100,000 次 P/E、均匀磨损和写放大为 1，外推平均写入速率。1.21→14.82 年比较 FCFS 与带 10% 余量的缓存感知调度；4.77→14.82 年才对应在已有缓存感知调度上增加余量。
5. **时间与能耗最优点**：GLM 5× 的最快配置为 H³、2×TP8、HBF 权重，时间 24,385 s；最低建模能耗配置为 H³、TP16、HBM 权重，能耗 37.62 MJ。两组最优结果不能当作同一个配置的表现。
6. **并行与请求分配**：2×TP8 是两个八 GPU 副本，共享处理同一总工作负载，不能误译为各自重复完整工作负载。GLM 使用 DPA 和理想 EP token 负载均衡假设。
7. **1× 与 5×**：1× 为原始长度的 100k 轮轨迹，5× 为拼接延长的 500k 轮轨迹；不是单纯把相同长度工作量增加五倍。平均输入长度由 22,558 增至 89,125 tokens。
8. **百分点与百分比**：表 7 各贡献项以基线能耗的百分点计，正值表示节能、负值表示新增开销；净节省一行按原表保留百分号。53.33 million 译为 5,333 万。
9. **单位与参考文献**：GB/TB 使用原表的十进制口径，未替换为 GiB/TiB。参考文献中文条目为阅读译名，完整作者、链接和 DOI 以相邻英文著录为准。原文的当前设备与版本陈述均保留其发表时语境。
